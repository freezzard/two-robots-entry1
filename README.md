Entry for the make.fun bounty **Two Robots in an Elevator**. `main.ts` runs a deterministic round-robin tournament over nine original candidate lines of awkward robot-to-robot elevator small talk, scores each one against the published judge brief (subject, machine logic, awkwardness, first-read funny, tightness), and writes the champion to `/output/entry.txt`. The winning line (95 characters): a robot confesses it rehearsed the elevator ride 400 times in simulation and still has nothing to say. The output is deterministic: every run writes byte-identical output, and the program gate-checks the field (one line, 1–200 characters, valid UTF-8) and replays the tournament before writing.

## Run it

```sh
node main.ts
```
